# Gafflo

Gafflo is a mobile-first room-matching web app prototype for renters in Ireland.

Tagline:

`Swipe rooms. Match smarter. Move better.`

## What it includes

- React + Vite
- Tailwind CSS
- React Router
- Mock room listings
- LocalStorage persistence
- Tenant profile flow
- Room match scoring
- Saved rooms shortlist

## Routes

- `/` Home
- `/profile` Tenant Profile
- `/rooms` Swipe Rooms
- `/saved` Saved Rooms

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Product scope

This is a frontend MVP and portfolio demo.

It does not include:

- backend APIs
- authentication
- payments
- chat
- real rental listings
- sensitive tenant documents

## Notes

The app is room-first rather than people-first. Matching focuses on budget, area, move-in date, lifestyle, and house rules.
