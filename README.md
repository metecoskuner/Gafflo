# Gafflo

Gafflo is a mobile-first room matching web app prototype for renters in Ireland.

## Features

- Tenant profile form
- Room swipe experience
- Compatibility match score
- Saved rooms
- Room details with match reasons
- LocalStorage persistence
- Mock data only

## Tech stack

- React
- Vite
- Tailwind CSS
- React Router
- JavaScript

## How to run

```bash
npm install
npm run dev
npm run build
```

## Demo disclaimer

This is a portfolio demo using mock data. No real rental listings or sensitive tenant documents are collected.
